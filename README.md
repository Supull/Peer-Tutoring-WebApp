Peer Tutoring Web Application

A full-stack web app connecting learners and tutors for seamless session scheduling, real-time chat, and secure account management. 
Deployed on AWS Cloud and presented to the Head of High School for potential institutional adoption.

Key Features

Role-Based Accounts: Tutor and learner registration with secure authentication (password hashing).
Session Management: Tutors set availability; learners request sessions; tutors approve/decline.
Real-Time Chat: Instant communication via Web Sockets.
Secure & Scalable: MySQL database backend, PHP server, deployed on AWS.

Tech Stack

Frontend: HTML, CSS, JavaScript
Backend: PHP
Database: MySQL
Realtime: Web Sockets
Deployment: AWS Cloud
